# Git Auto-Push Rule

Whenever any changes, feature implementations, bug fixes, or file edits are made to the Jewels by J workspace:
1. Automatically stage all changed files: `git add -A`
2. Commit with a concise, meaningful message: `git commit -m "<description>"`
3. Push immediately to GitHub: `git push origin main` (targeting `https://github.com/darnjoel/Jewels-by-J.git`)
4. Never leave completed changes uncommitted or unpushed unless specifically requested.
